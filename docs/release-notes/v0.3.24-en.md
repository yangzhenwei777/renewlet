# Renewlet v0.3.24

Renewlet v0.3.24 adds daily costs for one-time purchases and improves how expired subscriptions are sorted and displayed. Thanks to [@gitbs2b](https://github.com/gitbs2b) for [#75](https://github.com/zhiyingzzhou/renewlet/issues/75) and [@pivst](https://github.com/pivst) for [#76](https://github.com/zhiyingzzhou/renewlet/issues/76).

[中文 ->](./v0.3.24-zh.md)

---

## New Features

- One-time purchases now show daily costs: lifetime purchases use the actual number of days owned, while fixed-term purchases are spread over the service term.
- Payment type filters now distinguish auto-renewal, manual renewal, lifetime, and fixed-term subscriptions.

## Improvements

- The default order now keeps active subscriptions ahead of expired, paused, and cancelled ones, with inactive cards visually muted. Manually pinned subscriptions still take priority.
- Sorting by expiry date no longer puts expired subscriptions ahead of active ones.
- Manual exchange-rate refreshes now show progress and results, and continue using fallback rates if the refresh fails.
