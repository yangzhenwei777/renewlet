# Renewlet v0.3.1

Renewlet v0.3.1 improves performance and stability for subscription actions, notification history, and cloud backups, especially as your data grows.

[中文 ->](./v0.3.1-zh.md)

---

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

If your cloud backups contain many custom images, make sure existing snapshots can be downloaded before upgrading. Most users do not need to take action.

---

## Improvements

- Subscription lists, edits, and renewals are faster.
- Paging through notification history no longer reloads unrelated data.
- Cloud backups use less memory.
- Renewlet no longer preloads pages you have not opened after sign-in.
