# Renewlet v0.3.23

Renewlet v0.3.23 adds a follow-device language option and makes language behavior consistent across the interface, public pages, and notifications.

[中文 ->](./v0.3.23-zh.md)

---

## Before Upgrading

Cloudflare one-click deployment users should continue to run `Sync Renewlet Upstream` from the generated repository. This upgrade briefly enters maintenance mode; wait for the workflow to finish before continuing to use Renewlet.

## Improvements

- Language settings now include “Follow current device,” enabled by default for new accounts and demo mode. Existing language selections remain unchanged.
- Public status pages follow the visitor’s language. Scheduled notifications, Telegram, and calendars use the account preference; background content defaults to English when following the device.
- Docker and Cloudflare create a recovery point before data migration to reduce cross-version upgrade risk.

## Fixes

- Fixed untranslated text and mixed-language content that could appear on the first screen and in some settings.
- Fixed failed language saves sometimes reverting to stale account settings.
