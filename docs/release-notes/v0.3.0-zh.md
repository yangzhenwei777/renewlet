# Renewlet v0.3.0

Renewlet v0.3.0 完善 AI 识别后的编辑体验：现在可以直接管理家庭共享成员，草稿设置会完整保留，修正识别结果后也不会再被旧提示拦住添加。

[English ->](./v0.3.0-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

---

## 改进

- AI 草稿现在可以直接管理家庭共享成员。
- 自动续订、公开展示、提醒和家庭共享设置会完整保留。
- 切换 AI 草稿不会丢失已填写内容。

## 修复

- 修复预览没有错误时仍无法确认添加的问题。
- 修复 Docker 页面内更新耗时较长时可能失败的问题。
