# Renewlet v0.3.21

Renewlet v0.3.21 修复 Cloudflare 升级后统计、日历等内容为空，以及部分 Docker 用户升级后无法启动的问题。感谢 [@Xavier9896](https://github.com/Xavier9896) 在 [#70](https://github.com/zhiyingzzhou/renewlet/issues/70) 里的反馈。

[English ->](./v0.3.21-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream`。升级后会自动恢复列表、筛选、统计、标签、日历和调度数据，无需逐条编辑。

如果单个订阅的外部日历旧链接已经失效，请在设置中重新生成；“全部续费”链接不受影响。

Docker 用户请先把 `.env` 中的镜像标签改为 `0.3.21`，再运行：

```bash
docker compose pull
docker compose up -d
```

## 修复

- 修复 Cloudflare 跨版本升级后部分订阅数据视图为空的问题。
- 修复使用旧 Docker 启动入口时升级后无法启动的问题。
- 修复 Docker 页面内更新在较慢网络下容易超时，更新失败后可直接重试。
