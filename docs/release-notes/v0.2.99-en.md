# Renewlet v0.2.99

Renewlet v0.2.99 improves manual renewal and currency selection. Thanks [@pivst](https://github.com/pivst) for the feedback in [#63](https://github.com/zhiyingzzhou/renewlet/issues/63): expired subscriptions can now be restarted from a new date, and renewal can update price and currency at the same time.

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

---

## New Features

- Manual renewal now supports two modes: continue the next period, or restart from a new date.
- Continue mode only shows the next billing date it will advance to; restart mode is where start date and next billing date can be edited.
- Expired subscriptions open renewal as “restart” by default and return to active after submission.
- Price and currency can be updated during renewal.

## Improvements

- Currency selectors now follow the configured currency order across subscription forms, filters, statistics, and AI draft editing.
