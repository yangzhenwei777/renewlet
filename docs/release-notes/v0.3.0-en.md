# Renewlet v0.3.0

Renewlet v0.3.0 improves editing after AI recognition: manage family-sharing members directly, keep draft settings through import, and add corrected drafts without being blocked by stale warnings.

[中文 ->](./v0.3.0-zh.md)

---

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

---

## Improvements

- AI drafts can now manage family-sharing members directly.
- Auto-renew, public visibility, reminders, and family-sharing settings are preserved.
- Switching between AI drafts no longer loses your edits.

## Fixes

- Fixed an issue where import confirmation could remain unavailable even when the preview contained no errors.
- Fixed Docker in-app updates potentially failing when installation takes longer.
