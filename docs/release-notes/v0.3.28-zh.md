## 升级前请先读

一键部署用户请在原来的生成仓库运行 `Sync Renewlet Upstream`，不要重新点击一键部署。

升级前请备份数据。如果需要退回 v0.3.27 或更早版本，必须同时恢复升级前的数据，不能只换回旧镜像或旧 Worker；恢复备份后，升级期间新增和修改的数据也会回到备份时的状态。

## 新功能

- 语言设置新增「Русский」。选择「跟随系统」时，也能自动识别俄语。
