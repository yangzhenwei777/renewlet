# Renewlet v0.2.95

Renewlet v0.2.95 adds App Store as a Logo search source ([#57](https://github.com/zhiyingzzhou/renewlet/issues/57), thanks [@Xavier9896](https://github.com/Xavier9896)). When you manually search for a Logo, Renewlet can now find more mobile app and subscription-service icons alongside built-in icons and website favicons.

---

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

No manual settings migration is needed. The App Store source is enabled by default and uses the US storefront; enable CN in Settings if you want better Chinese app coverage. It is only used for manual Logo search, not import auto Logo selection or payment-method icon matching.

---

## New Features

- Manual Logo search can now include App Store icon results.
- App Store uses US by default; Settings lets you enable CN too, or keep CN as the only storefront.
- You can turn off the App Store source in Settings; built-in icons and website favicons still work.
