# Renewlet v0.3.21

Renewlet v0.3.21 fixes missing statistics, calendars, and other views after Cloudflare upgrades, plus a startup failure affecting some Docker upgrades. Thanks [@Xavier9896](https://github.com/Xavier9896) for reporting both issues in [#70](https://github.com/zhiyingzzhou/renewlet/issues/70).

## Read Before Upgrading

Cloudflare one-click deploy users should still run `Sync Renewlet Upstream` from the generated repository. The upgrade restores lists, filters, statistics, tags, calendars, and scheduling data automatically, with no need to edit subscriptions one by one.

If an external calendar link for an individual subscription no longer works, regenerate it in Settings. The “all renewals” link is unaffected.

Docker users should first change the image tag in `.env` to `0.3.21`, then run:

```bash
docker compose pull
docker compose up -d
```

## Fixes

- Fixed missing subscription views after Cloudflare upgrades across versions.
- Fixed startup failures after upgrading Docker deployments that use the previous entrypoint.
- Fixed Docker in-app updates timing out on slower connections and made failed updates retryable.
