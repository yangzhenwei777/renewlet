# Renewlet v0.3.29

Renewlet v0.3.29 fixes an AI recognition parameter error in the Docker version and lets you save S3 backups directly to the bucket root. Thanks to [@lmeyer](https://github.com/lmeyer) and [@sunnyhmz7010](https://github.com/sunnyhmz7010) for the reports.

## Upgrade Note

The Cloudflare site will be temporarily unavailable during this automatic upgrade and will come back online when it finishes.

## Improvements

- The S3 backup Prefix can now be left empty. Clear it and save to store new backups directly in the bucket root. Existing backups stay in their original location. [#87](https://github.com/zhiyingzzhou/renewlet/issues/87)
- Added an S3 addressing mode setting with Auto, Path-style, and Virtual-hosted options to match your storage provider's requirements.
- Cloud backup error details now show which step failed and why. Failures when automatically cleaning up old backups are also reported.

## Fixes

- Fixed AI recognition failing in the Docker version when using OpenAI's `gpt-6-sol` because of the unsupported `max_tokens` parameter. [#88](https://github.com/zhiyingzzhou/renewlet/issues/88)
- Fixed cancelled subscriptions still sending renewal, expiry, and repeat reminders. Family cost-sharing collection reminders continue according to their settings.
- Fixed upcoming notification previews showing outdated content after subscription changes.
- Fixed some built-in categories and payment methods appearing in English in the Russian interface, and added Russian support for AI-generated notes, categories, and tags.
