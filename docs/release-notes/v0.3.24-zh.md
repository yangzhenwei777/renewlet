# Renewlet v0.3.24

Renewlet v0.3.24 为一次性购买补充日均成本，并优化过期订阅的排序与展示。感谢 [@gitbs2b](https://github.com/gitbs2b) 在 [#75](https://github.com/zhiyingzzhou/renewlet/issues/75) 和 [@pivst](https://github.com/pivst) 在 [#76](https://github.com/zhiyingzzhou/renewlet/issues/76) 里的建议。

[English ->](./v0.3.24-en.md)

---

## 新功能

- 一次性购买也会显示日均成本：长期有效按实际持有天数计算“持有日均”，固定服务期按服务期摊算。
- 付费类型筛选细分为自动续费、手动续费、长期有效和固定服务期。

## 改进

- 默认排序会优先显示活跃订阅，已过期、已暂停和已取消订阅后置并弱化显示；手动置顶仍然优先。
- 按到期时间排序时，过期订阅不再排在活跃订阅前面。
- 手动刷新汇率时会显示进度和结果，失败时继续使用备用汇率。
