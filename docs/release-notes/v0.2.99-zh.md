# Renewlet v0.2.99

Renewlet v0.2.99 改进手动续订和货币选择体验。感谢 [@pivst](https://github.com/pivst) 在 [#63](https://github.com/zhiyingzzhou/renewlet/issues/63) 里的反馈：过期订阅现在可以按“重新开始订阅”处理，续订时也可以顺手调整价格和币种。

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

---

## 新功能

- 手动续订支持两种方式：延续下一期，或从新日期重新开始订阅。
- 延续模式只显示将推进到的下次扣费日；重新开始模式才显示可编辑的开始日期和下次扣费日。
- 过期订阅续订时默认进入“重新开始订阅”，提交后会恢复为 active。
- 续订时可以同时调整价格和币种。

## 改进

- 货币选择器现在严格跟随设置里的货币顺序，订阅表单、筛选、统计和 AI 草稿编辑里的顺序保持一致。
