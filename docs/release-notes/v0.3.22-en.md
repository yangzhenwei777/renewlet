# Renewlet v0.3.22

Renewlet v0.3.22 adds daily spending averages and improves calendar month switching.

[中文 ->](./v0.3.22-zh.md)

## New Features

- Daily spending averages are now shown in subscription cards, subscription details, the dashboard, statistics, and public status pages.

## Improvements

- The calendar keeps the current month visible while another month loads instead of returning to the loading skeleton.
