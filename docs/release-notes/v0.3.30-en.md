# Renewlet v0.3.30

Renewlet v0.3.30 improves the reliability of Cloudflare scheduled jobs and cloud backups, and makes Settings easier to navigate.

[中文 ->](./v0.3.30-zh.md)

---

## Before You Upgrade

Cloudflare one-click deployment users should continue to run `Sync Renewlet Upstream` from the existing generated repository. Do not start a new one-click deployment. The site will briefly enter maintenance mode during this upgrade, so wait for it to finish before using Renewlet again.

## Improvements

- Cloudflare renewals, notifications, and cloud backups now run in bounded steps. When one run does not have enough time or resources to finish, the next run continues from the saved progress instead of starting over.
- Multi-channel notifications now keep a result for each channel. Retries only send through channels that are still incomplete, so channels that already succeeded do not send the same notification again.
- When a scheduled WebDAV backup reaches the Cloudflare Free plan's request limit, it pauses and explains why. Fix the address or redirect configuration, then enable scheduled backups and save again to resume.
- Docker and Cloudflare now resolve time zones and daylight-saving transitions the same way, reducing unexpected times for reminders and scheduled backups.
- Advanced Settings are grouped into Resources & AI, Budget & Data, Cloud Backup & Calendar, and Public & Notifications, and load on demand. Section navigation is more reliable on mobile, including after going back or refreshing, and failed sections can be retried.
- Dashboard statistics and passkey functionality are handled on demand to reduce the work needed when the page first opens.
- Cloudflare deployment recovery now prints a command that can be copied and run directly.

## Fixes

- Fixed cancelled passkey sign-ins or switched authentication flows allowing an old request to affect the next operation.
- Fixed password-reset requests being cancelled by unrelated requests.
