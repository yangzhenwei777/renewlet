# Renewlet v0.3.29

Renewlet v0.3.29 修复了 Docker 版的 AI 识别参数报错，S3 备份也可以直接存到存储桶根目录了。感谢 [@lmeyer](https://github.com/lmeyer) 和 [@sunnyhmz7010](https://github.com/sunnyhmz7010) 的反馈。

[English ->](./v0.3.29-en.md)

---

## 升级提示

Cloudflare 本次自动升级期间，站点会暂时无法访问，升级完成后自动恢复。

## 改进

- S3 备份的 Prefix 可以留空，清空并保存后，新备份会直接存到存储桶根目录。已有备份不会自动搬过去。[#87](https://github.com/zhiyingzzhou/renewlet/issues/87)
- S3 备份新增「寻址模式」，可以按存储服务商的要求选择 Auto、Path-style 或 Virtual-hosted。
- 云备份出错时，详情会显示失败的步骤和具体原因；自动清理旧备份失败时也会提示。

## 修复

- 修复 Docker 版使用 OpenAI 的 `gpt-6-sol` 进行 AI 识别时，因 `max_tokens` 参数不受支持而失败的问题。[#88](https://github.com/zhiyingzzhou/renewlet/issues/88)
- 修复已取消的订阅仍发送续费、到期和重复提醒的问题。家庭共享收款提醒仍按原设置发送。
- 修复修改订阅后，待发送通知预览仍显示旧内容的问题。
- 修复俄语界面中部分内置分类、支付方式仍显示英文的问题，并补齐 AI 生成备注、分类和标签时的俄语支持。
