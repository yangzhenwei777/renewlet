# Renewlet v0.3.2

Renewlet v0.3.2 新增日历订阅管理，并优化订阅较多时的加载速度。设置页定位和常用弹窗的加载过程也更稳。

[English ->](./v0.3.2-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

如果配置过 `RENEWLET_CUSTOM_HEAD_SCRIPT`，请在升级前改为 `RENEWLET_CUSTOM_HEAD_HTML`，旧变量已移除。新变量支持完整的 Head HTML，只应放入可信代码；Docker 修改后需要重启，Cloudflare 修改后需要重新构建部署。没有用过这个配置可以忽略。

---

## 新功能

- 设置里现在可以统一管理“全部续费”和单个订阅的日历链接，包括复制、打开、重新生成和撤销。
- “添加到日历”现在明确区分持续同步和一次性添加。
- 自定义 Head 支持完整 HTML 片段，可以同时加入脚本、样式和 meta 信息。

## 改进

- 订阅较多时，列表、筛选、统计、日历和导出会减少重复加载。
- 订阅编辑、续订、详情、日历和导入弹窗在加载时不再出现空白或内容跳动。
- 设置页会等内容就绪后再定位，首次打开延迟加载的分区不再跳错位置。

## 修复

- 删除订阅时会同时撤销它的专属日历链接。
