# Renewlet v0.2.96

Renewlet v0.2.96 改进多币种订阅、统计口径和数据迁移体验。你可以为单个订阅显示自己选择的参考货币，统计和公开状态页会更清楚地标明汇率口径，导入导出也会更完整地保留图标和金额。

[English ->](./v0.2.96-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

单订阅参考价默认关闭，不会改变现有订阅卡片；需要时可以在设置页的“汇率与统计货币”里开启。

---

## 新功能

- 单订阅参考价：开启后，订阅卡片和详情弹窗会在原价下方显示一行小字参考价。原价仍是主显示，分账、公开状态页和 Public API 不会被改成参考货币。
- 参考货币可以跟随统计货币，也可以固定为你选择的货币。
- 统计和公开状态页会优先使用当月锁定汇率口径；暂未锁定时会标明实时口径。

## 改进

- 订阅金额和月度预算会保留更稳定的小数精度；异常金额输入会直接提示无效。
- Renewlet 导出和恢复现在会保留支付方式图标，Wallos 导入也能恢复更多本地图标资产。
- Public API 新增正式文档和 OpenAPI 3.1 文件，方便 CLI、Shortcuts 和自动化平台接入。
- 设置页的图标来源版本号过长时，可以悬停查看完整内容。
- 删除上传图片时，如果仍被订阅 Logo 或支付方式图标使用，会提示先替换，避免误删后页面缺图。
