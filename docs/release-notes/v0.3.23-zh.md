# Renewlet v0.3.23

Renewlet v0.3.23 新增跟随设备语言，并统一界面、公开页面和通知的语言表现。

[English ->](./v0.3.23-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream`。本次升级会短暂进入维护模式，请等待工作流完成后再继续使用。

## 改进

- 语言设置新增“跟随当前设备”，新账号和演示模式默认启用；已有语言选择保持不变。
- 公开状态页跟随访客语言；定时通知、Telegram 和日历使用账号偏好，跟随设备时后台内容默认使用英文。
- Docker 和 Cloudflare 在数据迁移前建立恢复点，降低跨版本升级风险。

## 修复

- 修复首屏和部分设置项可能出现未翻译文案或多语言混排的问题。
- 修复语言保存失败时可能恢复到旧账号设置的问题。
