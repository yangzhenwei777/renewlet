# Renewlet v0.2.96

Renewlet v0.2.96 improves multi-currency subscriptions, reporting currency basis, and data migration. You can show an optional reference currency for individual subscriptions, reports and public status pages now explain which exchange-rate basis they use, and import/export preserves more icons and money values.

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

Subscription price reference is off by default, so existing subscription cards keep their current display until you enable it in Settings -> Exchange rates and reporting currency.

---

## New Features

- Subscription price reference: when enabled, subscription cards and detail dialogs show a small reference amount below the original price. The original price remains primary, and cost sharing, public status pages, and Public API responses keep their own currency basis.
- The reference currency can follow your statistics currency or use a fixed currency you choose.
- Reports and public status pages prefer locked monthly exchange rates. When a month is not locked yet, they label the live-rate basis.

## Improvements

- Subscription prices and monthly budgets preserve decimal precision more reliably; invalid amount input is rejected clearly.
- Renewlet export/import now preserves payment method icons, and Wallos imports can restore more local icon assets.
- Public API now has official documentation and an OpenAPI 3.1 file for CLI tools, Shortcuts, and automation platforms.
- Long icon source version values in Settings can be viewed on hover.
- Uploaded images now explain when they are still used by subscription Logos or payment method icons before deletion.
