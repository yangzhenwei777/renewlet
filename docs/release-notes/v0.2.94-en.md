# Renewlet v0.2.94

Renewlet v0.2.94 makes exchange-rate updates more reliable. Previously, a source missing a few currencies, or returning rates as numeric strings, could make Settings show an exchange-rate format error. Now usable rates still update, and a clear notice explains any currencies that were temporarily filled.

---

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

No exchange-rate migration is needed. Existing FloatRates or Exchange API selections are kept. Switch to Frankfurter in Settings if you want to use the new default source.

---

## What Changed

- The new default exchange-rate source is Frankfurter, with steadier coverage.
- Fixed FloatRates updates failing when rates are returned as numeric strings.
- If a rate source is only missing a few currencies, Renewlet keeps the update successful and temporarily fills the missing currencies from another source or the built-in fallback.
- Settings now shows which currencies were filled and from where; the error response button only appears when the whole update fails.
