# Renewlet v0.2.92

Renewlet v0.2.92 改进 Cloudflare 部署下的内置图标更新稳定性（[#53](https://github.com/zhiyingzzhou/renewlet/issues/53)，感谢 [@yinyuangu](https://github.com/yinyuangu)）。Dashboard Icons、TheSVG 和 selfh.st icons 更新失败时，设置页不再一直卡在“更新中”，已有图标搜索也会继续可用。

[English ->](./v0.2.92-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

---

## 改进

- Cloudflare 版内置图标更新更稳定，Dashboard Icons、TheSVG 和 selfh.st icons 都能在设置页查看更新结果。
- 图标更新失败时会保留上一次可用结果，不影响继续搜索和选择已有图标。
- 设置页会显示更新成功或失败状态，关闭后重新打开也不会丢失最新结果。

## 修复

- 修复 Cloudflare 更新 Dashboard Icons 时可能出现 1102 或请求超时的问题。
- 修复图标更新失败后设置页可能长期停留在“更新中”的问题。
