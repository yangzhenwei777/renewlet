# Renewlet v0.3.25

Renewlet v0.3.25 improves subscription details, Add to Calendar, and upcoming renewals across different screen sizes.

[中文 ->](./v0.3.25-zh.md)

---

## Improvements

- Subscription detail titles and actions remain visible when the content is long. Add to Calendar can now be fully scrolled when screen space is limited.
- Long subscription names in Upcoming Renewals wrap cleanly, while large amounts stay aligned without breaking the layout or causing horizontal scrolling.
- Opening subscription details with the keyboard now focuses the title first and returns to the original entry when closed. Continuing to Edit or Add to Calendar no longer moves focus back to the page.
