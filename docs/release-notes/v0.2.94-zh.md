# Renewlet v0.2.94

Renewlet v0.2.94 让汇率更新更稳定。之前有些汇率来源少返回几个币种，或者把汇率数字换成字符串时，设置页可能直接报“汇率响应格式异常”。现在可用汇率会照常更新，少量缺失币种会临时补齐，并在设置页说明。

[English ->](./v0.2.94-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

这次不用手动迁移汇率设置。已经选择 FloatRates 或 Exchange API 的用户会保留原设置；想使用新的默认来源，可以在设置页切到 Frankfurter。

---

## 变化

- 新的默认汇率来源改为 Frankfurter，覆盖更稳。
- 修复 FloatRates 返回数字字符串时导致汇率更新失败的问题。
- 汇率来源只少几个币种时，Renewlet 会继续更新其它汇率；缺失币种会用其它来源或内置备用汇率临时补齐。
- 设置页会提示哪些币种用了补齐来源；只有所有来源都失败时才显示错误响应入口。
