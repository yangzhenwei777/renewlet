# Renewlet v0.3.30

Renewlet v0.3.30 主要提升 Cloudflare 定时任务和云备份的稳定性，也把设置页导航重新整理了一遍。

[English ->](./v0.3.30-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从原来的生成仓库运行 `Sync Renewlet Upstream`，不要重新点击一键部署。本次升级期间站点会短暂进入维护模式，请等待升级完成后再继续使用。

## 改进

- Cloudflare 的续订、提醒和云备份改为分段处理，单次运行时间或资源额度不够时会从断点继续，不必整轮重来。
- 多渠道提醒会分别记录发送结果，重试时只处理未完成的渠道，已经发送成功的渠道不会重复收到提醒。
- Cloudflare 免费版的 WebDAV 定时备份如果遇到单次请求上限，会自动暂停并说明原因；修正地址或跳转配置后，重新开启并保存即可继续。
- 统一 Docker 和 Cloudflare 对时区、夏令时切换时间的处理，提醒和定时备份更不容易错时。
- 设置页的高级选项按“资源与 AI”“预算与数据”“云备份与日历”“公开与通知”分组并按需加载。移动端目录跳转、返回和刷新后的定位更稳定，分区加载失败时可以直接重试。
- 首页统计和通行密钥功能改为按需处理，减少首次打开页面时的加载负担。
- Cloudflare 部署恢复流程生成的命令现在可以直接复制运行。

## 修复

- 修复取消通行密钥登录或切换认证流程后，旧请求可能影响下一次操作的问题。
- 修复密码重置请求可能被其它请求误取消的问题。
