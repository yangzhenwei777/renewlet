# Renewlet v0.2.98

Renewlet v0.2.98 新增家庭共享收款提醒（[#59](https://github.com/zhiyingzzhou/renewlet/issues/59)，感谢 [@pivst](https://github.com/pivst)）。可以在家庭共享里开启提醒，提前几天提醒自己向共享成员收款；成员也可以设置上车日期，更适合季付、半年付和多人不同时加入的共享场景。

[English ->](./v0.2.98-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

家庭共享收款提醒默认关闭，升级后不会改变现有订阅。需要时，可以在订阅的家庭共享区域里开启。

---

## 新功能

- 家庭共享收款提醒：为共享订阅开启提醒后，Renewlet 会在收款日前提醒账号主人向成员收款。
- 可以设置提前几天提醒，支持继承全局提醒天数。
- 成员可以设置上车日期，方便处理成员中途加入的共享订阅。
- 收款提醒只提醒账号主人，不会自动通知成员本人，也不会记录付款状态。
