# Renewlet v0.2.97

Renewlet v0.2.97 adds Cloudflare Turnstile human verification for login. Admins can enable it when needed so email password sign-in must pass a human check first, helping reduce brute-force and credential-stuffing attempts. Passkey sign-in, the MFA second step, and first-time setup are unchanged.

---

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

Turnstile is off by default, so upgrading does not change existing login behavior. Admins can configure and enable Cloudflare Turnstile from Settings -> Access security when they want to use it.

---

## New Features

- Login human verification: admins can enable email password login verification from Settings -> Access security -> Cloudflare Turnstile to help reduce brute-force and credential-stuffing attempts.
- The login page shows the Turnstile widget inside the email password form and submits login after verification.
- Passkey sign-in, the MFA second step, and first-time setup are not affected by Turnstile.
- The Turnstile widget follows Renewlet's light and dark theme.
