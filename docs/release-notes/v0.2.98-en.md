# Renewlet v0.2.98

Renewlet v0.2.98 adds collection reminders for family cost sharing ([#59](https://github.com/zhiyingzzhou/renewlet/issues/59), thanks [@pivst](https://github.com/pivst)). You can enable reminders inside cost sharing, choose how many days early Renewlet should remind you to collect from shared members, and set member join dates for subscriptions where people joined at different times.

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

Cost sharing collection reminders are off by default, so upgrading does not change existing subscriptions. Enable them from the cost sharing section when you want to use them.

---

## New Features

- Cost sharing collection reminders: Renewlet can remind the account owner to collect from shared members before a collection date.
- Reminder timing can be customized or inherit the global reminder days.
- Members can have join dates, which helps with shared subscriptions where people joined later.
- Collection reminders only remind the account owner. They do not notify members directly or track payment status.
