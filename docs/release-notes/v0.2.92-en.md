# Renewlet v0.2.92

Renewlet v0.2.92 improves built-in icon update stability on Cloudflare deployments ([#53](https://github.com/zhiyingzzhou/renewlet/issues/53), thanks [@yinyuangu](https://github.com/yinyuangu)). When Dashboard Icons, TheSVG, or selfh.st icons updates fail, Settings no longer stays stuck in an updating state, and existing icon search remains available.

## Read Before Upgrading

Cloudflare one-click deploy users should still upgrade from the generated repository by running `Sync Renewlet Upstream`. Do not click the one-click deploy button again. If an older generated repository does not have this entry yet, add it once from the [Cloudflare deploy documentation](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.md#existing-one-click-deploy-users).

---

## Improvements

- Built-in icon updates are more stable on Cloudflare, with visible update results for Dashboard Icons, TheSVG, and selfh.st icons in Settings.
- Failed icon updates keep the last usable result, so existing icon search and selection continue to work.
- Settings now shows success or failure after an update, and reopening the page keeps the latest result visible.

## Fixes

- Fixed Dashboard Icons updates on Cloudflare that could hit 1102 errors or request timeouts.
- Fixed Settings sometimes staying stuck in an updating state after an icon update failed.
