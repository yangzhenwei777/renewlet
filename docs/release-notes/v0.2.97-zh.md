# Renewlet v0.2.97

Renewlet v0.2.97 新增 Cloudflare Turnstile 登录人机验证。管理员可以按需开启，让邮箱密码登录先通过人机验证，用于降低爆破和撞库风险；通行密钥登录、身份验证器二阶段和首次初始化流程不受影响。

[English ->](./v0.2.97-en.md)

---

## 升级前请先读

Cloudflare 一键部署用户仍然从生成仓库运行 `Sync Renewlet Upstream` 升级，不要重新点一键部署按钮。旧生成仓库如果还没有这个入口，按 [Cloudflare 部署文档](https://github.com/zhiyingzzhou/renewlet/blob/main/docs/cloudflare-workers-deploy.zh-CN.md#旧一键部署用户) 一次性补上。

Turnstile 默认关闭，升级后不会改变现有登录流程。需要时，管理员可以在设置页的“访问安全”中配置并启用 Cloudflare Turnstile。

---

## 新功能

- 登录人机验证：管理员可以在“设置 -> 访问安全 -> Cloudflare Turnstile”启用邮箱密码登录人机验证，降低爆破和撞库风险。
- 登录页会在邮箱密码登录表单中显示 Turnstile 小部件，验证通过后再提交登录。
- 通行密钥登录、身份验证器二阶段和首次初始化流程不受 Turnstile 影响。
- Turnstile 小部件会跟随 Renewlet 的明暗主题。
